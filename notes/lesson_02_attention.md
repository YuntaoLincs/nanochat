# 第 02 课：注意力机制 —— 从点积到多头

## 核心直觉

Token 不是孤立存在的。为了预测下一个词，每个 token 需要从序列中的其他位置**收集信息**。
注意力机制（Attention）就是实现这种"信息收集"的机制。

---

## Q、K、V 的来源

Q、K、V 全部由同一个输入 `x` 线性变换而来：

```python
Q = x @ W_q   # 我在寻找什么
K = x @ W_k   # 我能提供什么
V = x @ W_v   # 我实际携带的信息
```

这就是"**自注意力（Self-Attention）**"名称的由来——Q、K、V 都来自自身。

---

## 注意力权重的计算

```
注意力权重 = softmax( Q · Kᵀ / √d_k )
```

- `Q · Kᵀ` 是点积，衡量"我寻找的"和"你能提供的"之间的**匹配程度**
- 点积越大 → 权重越高 → 从该位置收集更多信息
- `√d_k` 是缩放因子，防止点积值过大导致 softmax 梯度消失

---

## "相关性"从哪里来？

关键问题：模型是怎么学会判断哪些位置"相关"的？

答案：`W_q` 和 `W_k` 是**可训练参数**，通过**反向传播**不断被修正。

- 训练目标：预测下一个 token 的损失最小化
- 模型从未被明确告知"第3个词应该关注第1个词"
- "语义相关性"是从损失信号中**涌现**出来的，不是人工设计的

出处：*Attention Is All You Need*（Vaswani et al., 2017）

---

## 苏格拉底式问答回顾

| 问题 | 答案 |
|------|------|
| token 是平等地收集所有位置的信息吗？ | 不是，通过注意力权重有选择地收集 |
| 重要程度由什么决定？ | Q 和 K 的点积（方向相近 → 点积大 → 权重高） |
| W_q 和 W_k 是固定的吗？ | 不是，是可训练参数 |
| 模型怎么知道该关注哪里？ | 反向传播修正 W_q、W_k，相关性从损失中涌现 |
